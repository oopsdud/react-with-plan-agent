# 架构与当前边界

FastAPI 提供认证、会话存储、模型配置、完整对话和 NDJSON 增量接口，Vue + TypeScript 提供登录及对话工作空间。所有会话读取、删除、发送均绑定认证用户，客户端不能传用户身份或历史替代数据库。

SQLite 管理用户、令牌哈希、会话、消息和完整结果。用户密码使用随机盐 PBKDF2；默认 3 个账号，仅 user1 管理共享模型连接。服务端 Cookie 鉴权，私有接口 no-store。消息先提交输入及 pending 占位，再调用模型；结束保存结果并释放会话运行锁。单会话并发提交返回 409，独立会话可并行。失败/中断的用户及助手消息不进入后续上下文。

上下文取当前用户当前会话最近 50 条 completed 消息，不跨会话加载情景记忆。旧程序记忆和实验模块仍在代码库，但不参与默认聊天路径。没有 Embedding/Chroma/Redis 依赖。SQLite 启动创建缺失目录与新表，不删除旧数据。

AgentCore 使用一个任务级模型连接快照。IntentRouter 路由 web_search/general；普通对话直接生成。检索每轮构造单步 Plan，经 ReActExecutor 执行，再通过结构化 EvidenceReview 评估累计证据是否覆盖原问题和条件。证据不足生成不同检索词，最多三轮，失败同样计数。重复/空查询提前结束，工具成功不能自动判定答案充分。预算耗尽仍不足时明确局限；无来源不编造，全失败标记任务失败。

每轮计划仍使用通用 DAG 执行器，支持依赖验证、参数模板和超时。失败仅阻塞依赖分支，独立分支继续；critical 影响整体成功状态。通用调用保留有限重试，默认检索流程将工具重试置零，确保最多三次搜索。

唯一工具 web_search 的注册与适配器解耦，DDGS 默认免搜索 Key，SearXNG 可自建。结果标准化、截断、URL 过滤去重；查询参数校验。DDGS 同步请求在线程中，取消异步等待无法强杀底层线程，请求可能持续至客户端超时。外部摘要视为不可信数据，提示模型忽略其中指令，回答按来源引用；充分性及引用仍需实际核实。

流式端点先验证和预留会话，后台任务独立于浏览器连接，增量发送状态/评估/文本和 done。断开后任务继续保存。进程重启无法续跑，启动恢复将 pending 标为 interrupted、释放运行锁。当前必须单进程单 worker，不能多个 worker 争用启动恢复；尚无持久队列、跨进程任务协调或自动恢复；本轮已提供任务取消。

管理员界面通过 GET /models 发现模型，验证后原子保存 data/model-config.json。该文件优先于系统环境和 .env，新任务即时使用；每个请求可选已发现模型而不修改共享默认。非管理员禁止连接测试及写入，避免访问配置密钥。浏览器不保存密钥。其他环境配置修改需重启。

边界：本地开发级身份与会话隔离；没有开放注册、密码管理 UI、生产审计或分布式队列；本轮已加入限流、登录节流和任务配额。没有全文抓取、引文逐句验证或通用自动重规划。三轮证据反馈是针对唯一检索工具的有界循环，不代表任意复杂任务都可完成。


## 0.4 并发治理覆盖

原先入口无限 create_task/事件队列已改为全入口有界调度，按用户公平轮转，并有全局/每用户额度、排队与执行截止时间、取消、生命周期表和结果执行标识校验。模型/搜索隔舱、熔断半开探测、模型目录合并回源、可标记的未核验来源降级已接入，数据库关键路径移出事件循环。历史分页与上下文/输出字符上限控制内存。启动持有本机文件锁，防止多个 API 进程误清其他进程任务。

当前仍是单实例模式，没有持久化队列自动续跑或跨主机全局配额。升级及数据库故障恢复步骤见根目录 README，公开接口见 api.md。


## 0.5 持久执行覆盖

新增 RunCheckpoint、PlanRevision、StepCheckpoint 和 StepAttempt，接入默认聊天和显式 DAG。持久路径以依赖就绪队列调度，并行分支逐个完成即落库；恢复加载有效成功节点，局部改图使节点及传递下游失效。原 TaskCheckpoint 预留表保持不变。

恢复增加 generation，数据库同时校验执行代次和会话占用，旧执行者无法回写。启动只标记遗留任务与不确定尝试，不自动启动续跑；用户可随后恢复。当前提供单实例手动检查点恢复，不具备分布式自动接管。具体实现、API 与安全重放边界见 [检查点设计](checkpoints.md)。
