63 个 Python 测试全部通过。包括：30 个任务竞争时全局/每用户并发上限与轮转；排队超时、运行超时、取消排队/运行任务后释放额度；跨用户读/取消任务拒绝；旧 run_id 不可覆盖新任务；请求去重及内容冲突；排队后的模型连接快照；慢消费者产生 1000 个事件时有界断流且结果仍保存；数据库保存失败明确报错；半开单探测、旧在途成功不能关闭新熔断；同步线程取消后仍占实际额度；模型目录合并回源、旧缓存不跨密钥；登录节流、进程锁、消息分页及上下文边界。原有检索三轮和 DAG 独立分支继续执行的回归保留。

10 个前端测试全部通过，vue-tsc 与 Vite 构建通过。覆盖原有接口/来源安全、模型配置，以及排队状态和服务端取消、429 未受理时撤回乐观消息并保留输入及重试建议。
