# 审核与验证（0.3.0）

本轮加入账号登录、SQLite 会话与消息持久化、按用户及会话隔离的上下文、对话模型选择、NDJSON 增量回答和最多三轮的检索证据反馈。前端采用独立滚动区、动画帧合并输出和移动端导航抽屉。

39 个 Python 测试覆盖认证/退出/令牌失效、密码哈希、注册关闭、管理员配置权限、跨用户会话访问拒绝、服务端历史上下文、不同会话隔离、模型选择、失败记录、运行互斥、重启中断恢复、增量事件和持久化，以及检索预算、充分提前停止、不足再检索、重复查询、空结果、错误等。原有 DAG 关键失败与独立分支继续执行的回归测试保留。

8 个前端测试覆盖带 Cookie 的模型/会话请求、跨块 UTF-8 解码、流式终止检查、登录入口、注册禁用、外部文本/代码/来源安全，以及模型发现与配置保存。vue-tsc 类型检查与 Vite 生产构建通过。

Chrome 浏览器使用独立临时数据库和测试 HTTP 模型/SearXNG 服务，走生产 SDK 的真实 HTTP 与 SSE 适配器，再由后端转换为 NDJSON。已验证登录、保存模型配置、对话选择模型、三轮证据评估、来源、执行详情、历史切换、刷新恢复、退出后第二账号无历史且无法读取第一账号会话、390px 手机布局。未出现 JS 异常，测试不使用真实模型凭证或额度。

真实模型的 JSON/流式能力、凭证与网络需用户接入后验证。之前已通过本机 DDGS 实际公开网页检索检查；本轮完整浏览器回归采用可重复的测试服务。运行边界见 [架构说明](architecture.md)。
