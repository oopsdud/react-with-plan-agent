错误处理

422 表示参数校验失败，404 表示工具不存在，500 表示服务异常。/chat 返回 HTTP 200 时仍需检查 success、error 和每个步骤的 status。

前端调用示例

import { AgentAPI } from './api.mjs';

const api = new AgentAPI(location.origin);
const result = await api.chat({
  user_input: '查询张三的员工信息',
  user_id: 'default_user',
  session_history: []
});

console.log(result.answer, result.steps);

交互约定

对话只保留在当前页面内存中；连接地址和调试用户 ID 保存在浏览器。仅识别意图不会执行工具，也不会加入对话历史。

请求超时只停止前端等待，不能保证后端停止执行。写入任务状态不明时，请先核实结果再重试。
